# Vignette.guide — винетки и пътни такси в Европа

Въвеждаш маршрут, дати и превозно средство и сайтът показва коя винетка е нужна за всяка държава,
най-евтината комбинация от срокове, отделните такси (Тауерн, Бренер, мостове) и **само официални
линкове**. Статичен Next.js сайт без сървър и без база.

## Как работи

- **Маршрут:** OSRM (`NEXT_PUBLIC_OSRM_URL`, по подразбиране демо сървърът `router.project-osrm.org`, който **не е за продукция**; за пускане вземете хостван OSRM/GraphHopper или си вдигнете свой).
- **Търсене на места:** Photon (автодовършване), а при натискане на бутона и Nominatim (разбира и „Мюнхен“, „Виена“). Nominatim е само при явно действие, както изискват правилата му.
- **Държави по маршрута:** в браузъра, по границите от Natural Earth (`world-atlas`).
- **Най-евтина комбинация:** `src/lib/cover.ts` (динамично програмиране върху датите в държавата).
- **Курсове:** ЕЦБ, обновяват се при всеки build (`scripts/fetch-rates.mjs`).

## Данни

Всичко е в `src/data/countries.ts`, с източник и дата на проверка за всяка държава.
Проучването и цитатите са в `RESEARCH.md`. Където правило не е потвърдено, валидността е моделирана
консервативно (по-кратко), а цената е `null`. Така сайтът никога не препоръчва невалидна винетка
и вместо това праща към официалния сайт.

## Команди

```bash
npm install
npm run dev
npm test        # срокове, най-евтина комбинация, 18-те дни в Австрия, уикенд в BG…

```
